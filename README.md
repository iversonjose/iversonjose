## About

I'm a software engineer and systems architect with **four years of hands-on programming** across the **LAMP and MERN stacks**, focused on building scalable, secure, and maintainable enterprise systems — not just applications. I write code every day, across TypeScript, PHP, Python, and Java. I co-founded [DIcode Digital Solutions](https://github.com/DIcode-Digital-Solutions), where we build operational workflow software purpose-built for the African market: systems that are affordable, intuitive, and production-ready.

My current specialization is **LLM application engineering** — I designed and shipped Wazi AI, a multi-tenant RAG-based knowledge management platform with department-scoped querying and Git-like document version control, deployed in a live enterprise environment.

My engineering philosophy is grounded in system design, security-first architecture, and the belief that **reliability isn't about preventing all failures — it's about working correctly when they happen.**

## Engineering Principles

The standards I hold my work to:

- **Security is not an afterthought.** Auth, RLS, rate limiting, and secrets management are designed in from day one — not bolted on later.
- **Architecture before implementation.** Data models, API contracts, and failure modes are defined before a single line of code is written.
- **Observable by design.** If you can't measure it, you can't manage it. Structured logging, distributed tracing, and SLOs are non-negotiable in production.
- **SOLID, DRY, KISS, YAGNI.** Build the simplest version that solves the real problem. Clean interfaces. No speculative abstractions.
- **Systems, not scripts.** The goal is software that outlasts the developer who wrote it.
