## Engineering Principles

The standards I hold my work to:

- **Security is not an afterthought.** Auth, RLS, rate limiting, and secrets management are designed in from day one — not bolted on later.
- **Architecture before implementation.** Data models, API contracts, and failure modes are defined before a single line of code is written.
- **Observable by design.** If you can't measure it, you can't manage it. Structured logging, distributed tracing, and SLOs are non-negotiable in production.
- **SOLID, DRY, YAGNI.** Build the simplest version that solves the real problem. Clean interfaces. No speculative abstractions.
- **Systems, not scripts.** The goal is software that outlasts the developer who wrote it.
